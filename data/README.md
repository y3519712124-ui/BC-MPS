# MUUFL Gulfport input data

The experiments use Campus 1 from the original [MUUFL Gulfport repository](https://github.com/GatorSense/MUUFLGulfport). Download `muufl_gulfport_campus_1_hsi_220_label.mat` from `MUUFLGulfportSceneLabels/` there, observing the data owners' conditions and citations. Original imagery and annotations are not redistributed in this repository. The code license does not change their terms.

Prepare the downloaded file from the repository root:

```bash
python scripts/prepare_data.py --source /path/to/muufl_gulfport_campus_1_hsi_220_label.mat
```

On Windows, quote a path containing spaces. The script verifies the original MAT SHA-256 and array properties and creates `data/muufl_spatial.npz` with:

| Key | Shape | Meaning |
| --- | --- | --- |
| `hsi` | 325 x 220 x 64 | Hyperspectral float32 inputs |
| `lidar` | 325 x 220 | First-return DEM, band 0; float32 |
| `labels` | 325 x 220 | Original classes shifted to 0--10; background -1 |

`PROVENANCE.json` records the upstream URL, original/prepared file hashes and class counts. Normalization is fitted separately for each allocation on all pixels in its assigned training regions, including unlabeled and border pixels.

There are 24 allocated tiles per scene. Four are allocated to calibration, but only three contain retained labeled calibration centers in each primary split. The three allocations have four, three, and three nonempty test tiles, respectively. Masks erode each tile separately by five pixels for complete 11 x 11 patch support separation. Geometry masks are regenerated by `split_tiles` in `code/original_snapshot/protocol.py` using the seeds in `configs/paper.json`.
